# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/ryotan/rmk-cornix/security/advisories/new), not in a public issue.

This repository is the Cornix configuration of [RMK](https://github.com/HaoboGu/rmk): the keymap, the status LED logic, the build and the flashing script. A vulnerability in RMK itself, such as its BLE stack or its Vial protocol handling, belongs to RMK; please report it there. If you are unsure which side it is on, report it here and it will be forwarded.

This is a personal project with a single maintainer, so there is no guaranteed response time. The fix is released first, and the advisory is disclosed publicly once the fix is available. Please do not disclose the details before then.

## Supported versions

Only the latest commit on `main` receives security fixes.
